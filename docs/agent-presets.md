# Пресеты агента

Пресет — готовый первый запрос, который предлагается на пустом экране чата любого агента. По сути это настраиваемые стартовые чипы: раньше они были только у встроенного Projector и задавались кодом, теперь их можно завести для всех агентов.

Пресет бывает двух видов:

- **Текст** — при нажатии `prompt` попадает в поле ввода, пользователь может его поправить и отправить.
- **Форма** — если в пресете есть `form` (Vue-разметка `Form` или `IntelligentForm`), при нажатии открывается форма. После заполнения значения уходят агенту вместе с `prompt`.

## Где хранятся

| Вид             | Файл                                          | Область                  |
| --------------- | --------------------------------------------- | ------------------------ |
| Личные пресеты  | `$XDG_DATA_HOME/projector/agent/presets.json` | Все проекты и все агенты |
| Пресеты проекта | `.projector/presets.json` в папке проекта     | Только этот проект       |

Личные пресеты создаются в **Настройки → Пресеты агента**. Пресеты проекта создаются в **Настройки проекта → Пресеты проекта** или пишутся в файл вручную.

Пресеты проекта попадают на стартовый экран из доверенного файла. Доверие привязано к SHA-256 хешу и хранится в `agent/preset-trust.json`. Файл, который Projector создаёт или меняет через настройки либо команду агента, доверяется автоматически, если он новый или уже был доверен. Файл, пришедший с репозиторием, и изменения извне остаются недоверенными: их нужно проверить и выдать доверие в настройках проекта. Это защищает от формы со скриптом из чужого репозитория: markup формы исполняется в браузере так же, как формы ответов.

## Формат

```json
{
  "version": 1,
  "presets": [
    {
      "id": "preset-a1b2c3d4",
      "title": "Ревью изменений",
      "description": "Проверить diff перед коммитом",
      "prompt": "Проверь изменения в Git и ничего не меняй.",
      "form": "<IntelligentForm summary=\"Ревью\"><Field name=\"scope\" label=\"Что проверить\" :options=\"['весь diff','только staged']\" /></IntelligentForm>"
    }
  ]
}
```

- `title` — подпись чипа, обязательна (до 80 символов).
- `prompt` — текст запроса (до 8000 символов). Может быть пустым, если есть `form`.
- `form` — необязательная Vue-разметка (до 20 000 символов). Форма должна содержать `Form` или `IntelligentForm`; `AgentFormPanel` сам подключит её к чату.
- `id` генерируется сервером (`preset-xxxxxxxx`). Пресет проекта с тем же `id` заменяет личный.
- `description` — пояснение в подсказке чипа (до 400 символов).

Неизвестные поля игнорируются. Пресет без названия или без `prompt`/`form` отбрасывается при чтении.

## Команды

Агент видит и меняет пресеты через обычные команды IDE:

| Команда                   | Что делает                                                                 |
| ------------------------- | -------------------------------------------------------------------------- |
| `ide.agent.presets.list`  | Список личных и проектных пресетов, статус доверия и путь к файлу проекта. |
| `ide.agent.preset.create` | Создаёт пресет; `scope` — `global` (по умолчанию) или `project`.           |
| `ide.agent.preset.save`   | Меняет название, описание, текст или форму.                                |
| `ide.agent.preset.delete` | Удаляет пресет.                                                            |

`create` и `save` принимают `form` — так агент может написать форму прямо в пресет. Это удобный путь: пользователь просит «сделай пресет с формой для настройки задачи», агент вызывает команду, и на следующем пустом чате уже есть готовый чип.

Для проектного пресета ответ содержит `projectTrusted`: новый файл и правка уже доверенного файла сохраняют доверие, а файл из репозитория или изменённый извне нужно доверить в настройках проекта.

## API

- `GET /api/agent/presets?projectId=…` — `{ presets, file, project? }`.
- `POST /api/agent/presets` — `{ preset, projectId? }`.
- `PUT /api/agent/presets/:id` — `{ preset, projectId? }`.
- `DELETE /api/agent/presets/:id?projectId=…`.
- `PUT /api/agent/presets/trust` — `{ projectId, trusted }`.

Изменяющие запросы требуют локальную страницу Projector, как и запись ролей.

## Стартовый экран

`AgentWelcome` читает личные пресеты и доверенные пресеты проекта через `loadStartPresets` и показывает их группами «Проект» и «Общие». Текстовый пресет подставляет `prompt` в композер, форма открывается на месте чипов. После отправки формы в чат уходит обычный `AgentFormAnswer` — пользовательское сообщение сохраняет markup и значения, поэтому форма остаётся читаемой в истории.

Стартовый экран работает у всех агентов, включая внешних: `plain`-режим больше не скрывает пресеты.
