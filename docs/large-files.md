# Реестр больших файлов

Файл живёт здесь, пока в нём больше 400 строк (для `.vue` — 500). Реестр хранится в `extra.largeFiles` файла `feod.config.mjs`. Правило `large-files` требует запись для каждого файла выше порога, запрещает рост выше потолка и просит снизить потолок или удалить запись после сокращения файла; таблица ниже ведётся вручную в соответствии с реестром.
