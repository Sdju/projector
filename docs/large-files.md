# Реестр больших файлов

Источник реестра — `extra.largeFiles.files` в [feod.config.mjs](../feod.config.mjs).
Конфигурация содержит актуальный список исключений и планы их разбиения.

Правило проверяет текст, который получает от Oxlint. Порог — 400 строк, для
`.vue` — 500 строк кода из `<script>`. При оценке размера Vue-компонента
учитываем также шаблон и стили.

Для каждого превышения в конфиге нужны текущий потолок и план разбиения.
При сокращении файла до размера выше порога потолок опускается до нового
размера. Когда файл достиг порога или удалён, запись удаляется.
