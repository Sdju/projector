# Интеграции

[Начало работы](../README.md) · [Использование](usage.md)

На `/settings` есть раздел «интеграции». Каждая интеграция имеет переключатель, параметры и собственную авторизацию. Общий реестр находится в `server/modules/integrations/index.ts`, реализация GitHub — в `server/modules/integrations/github.ts`.

Настройки и учётные данные сохраняются сервером в `$XDG_DATA_HOME/projector/integrations.json` (по умолчанию `~/.local/share/projector/integrations.json`), с правами `0600` и атомарной заменой файла. Токен хранится в этом файле и не возвращается в браузер; `localStorage` для настроек не используется. Существующие настройки интерфейса и модели остаются в `launcher.json` и `providers.json`.

### GitHub

1. Укажите папку для импорта. Подключение через токен включает интеграцию автоматически; для Device Flow сначала сохраните параметры интеграции.
2. Авторизуйтесь одним из способов:
   * **Через браузер:** создайте [GitHub OAuth App](https://github.com/settings/developers), включите **Enable Device Flow**, внесите её **Client ID** в настройки Projector. Homepage и callback URL при регистрации можно указать `http://localhost:4177`; Device Flow не использует callback или Client secret. Нажмите «войти через GitHub», откройте ссылку, введите показанный код и подтвердите доступ. Projector запрашивает `repo` для импорта приватных репозиториев.
   * **Personal Access Token:** fine-grained token с доступом к нужным репозиториям и **Contents: read**, либо classic token со scope `repo` для приватных репозиториев. Projector проверяет токен через `/user` перед сохранением. Доступ к организациям может требовать разрешения организации / SSO.
3. На `/projects` откройте «импорт из GitHub». Выберите репозиторий из списка или вставьте `owner/repository` / ссылку GitHub. Список доступных репозиториев загружается страницами по 50, фильтр действует на загруженные записи.

Импорт требует установленного `git`. Репозиторий клонируется по HTTPS в `<папка импорта>/<owner>/<repository>` и регистрируется в `projects.json`. Для JS-проектов читаются `package.json` и команды запуска. Для остальных добавляется безопасная команда `git status`, которую можно заменить в карточке проекта. Projector не устанавливает зависимости и не запускает код при импорте. Существующие папки не перезаписываются; их можно добавить обычным способом как локальный проект.

«Выйти» удаляет сохранённый токен из Projector. Для отзыва доступа на стороне GitHub используйте настройки аккаунта GitHub. Выключение интеграции запрещает новые импорты, сохраняя её параметры и уже добавленные локальные проекты.

Проверка входа, файловых настроек и импорта без обращения к настоящему GitHub:

```bash
node --test tests/integrations.test.mjs tests/launcher.test.mjs
```

Тесты используют временные XDG-каталоги, подмену GitHub API и Git; проверяют обязательную авторизацию, приватные репозитории, пагинацию, Device Flow (ожидание, ограничение частоты, истечение и отмену), права файла, отсутствие токена в публичном API и Git URL, повторный и параллельный импорт.
