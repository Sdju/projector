# Использование Projector

[Начало работы](../README.md) · [GitHub и интеграции](integrations.md)

## Режимы запуска

```bash
./bin/projector toggle    # показать/скрыть палитру
./bin/projector --tray    # запуск без окна
./bin/projector --native  # GTK4
./bin/projector --window  # Chromium app-окно
./bin/projector --browser # браузер по умолчанию
./bin/projector quit     # завершить сервер и его процессы
```

После `vp run desktop` доступна команда `projector` в `~/.local/bin` и пункт меню приложений. Установка ссылается на checkout; после переноса каталога повторите её. Автозапуск настраивается средствами рабочего окружения командой `projector --tray`.

## Поиск и запуск

Главная страница — поиск приложений и сохранённых проектов. Начните вводить название: поддерживаются неточные совпадения, описание и ключевые слова. ↑↓ выбирают результат, Enter запускает. Пустое поле показывает до семи результатов с приоритетом часто запускаемых приложений.

В системном и отдельном веб-окне палитра скрывается после запуска, по Esc и при переключении в другое приложение. Перемещение фокуса между полем и результатами её не закрывает. В обычной вкладке остаётся подтверждение запуска, Esc очищает поиск. Ошибка запуска остаётся видна в интерфейсе.

Режим по умолчанию выбирается на `/settings`. CLI-флаги выбирают интерфейс только для текущего вызова. Настройки и история: `~/.local/share/projector/launcher.json` (или `$XDG_DATA_HOME/projector/launcher.json`).

В KDE Projector автоматически регистрирует `Ctrl+Alt+Space`: нажатие показывает/скрывает выбранную палитру. Сочетание можно изменить или выключить на `/settings`. Занятые другим приложением сочетания не перехватываются. Настройки показывают реальное состояние регистрации хоткея.

В других рабочих окружениях назначьте удобное сочетание в настройках клавиатуры на команду `projector toggle`. Если команда ещё не установлена в PATH, используйте абсолютный путь к `bin/projector` с аргументом `toggle`.

## Работа в трее

После запуска Projector остаётся в трее даже при скрытой палитре. Клик по иконке открывает поиск в выбранном режиме. Контекстное меню: поиск, проекты, настройки, перезапуск и выход. «Выйти из Projector» завершает фоновые процессы Projector и запущенные им проекты; Esc только скрывает палитру.

`projector --tray` запускает приложение без показа окна. Эту команду можно добавить в автозапуск рабочего окружения; автоматически автозапуск не устанавливается.

«Перезапустить» в меню трея полностью завершает сервер и системный интерфейс, останавливает все терминалы и запущенные в них процессы, затем запускает Projector заново в трее. Настройки сохраняются; терминальные сессии не восстанавливаются.

Трей использует StatusNotifierItem / DBusMenu и требует поддержки этого протокола рабочим окружением. В KDE Plasma проверены реальное нажатие хоткея, повторное скрытие и меню трея.

## Требования интерфейсов

* Системное окно: Linux, Node.js 24, GTK4 и GObject Introspection (включая GioUnix). `node-gtk` использует системные библиотеки. Для GTK Python не нужен. Окно сохраняется в отдельном Node-процессе и повторно вызывается через D-Bus.
* Отдельное веб-окно: Chromium-совместимый браузер. Используется отдельный профиль Projector; профиль текущего браузера не меняется. Фокус, скрытие и повторный показ реализованы через `xdotool` и `xprop` в X11.
* Обычная страница: браузер по умолчанию через `xdg-open`.

Поиск системных приложений во всех режимах использует GIO через `node-gtk`. GIO читает установленный каталог `.desktop`, учитывает скрытые записи и запускает приложения с поддержкой `Exec`, `Terminal` и D-Bus activation. Если каталог недоступен, поиск проектов остаётся доступным с сообщением об ошибке. Трей и KDE-хоткей используют `dbus-next`; необязательный биндинг `usocket` отключён, обычного session D-Bus сокета достаточно.

## Проекты

Управление проектами: `/projects` или ссылка «Проекты» в палитре.

1. Добавьте проект по пути на диске.
2. «Прочитать» подтянет имя и скрипты из `package.json`.
3. Запускайте конкретную команду (`dev`, `preview`, своя).
4. Режим **сервер** запускает команду в терминале. Режим **окно** после старта открывает URL в app-окне.

Список проектов: `~/.local/share/projector/projects.json`.

## Обзор проекта

Страница проекта открывается как лёгкое рабочее пространство: слева **Файлы / Поиск / Git**, в центре редактор текстовых файлов и Markdown, справа существующие терминалы Shell, Codex и Claude Code. Ширину панелей можно менять перетаскиванием границ или стрелками после фокуса на границе. На узком экране терминал располагается под обзором.

Дерево загружает папки по мере раскрытия, скрывает зависимости и сборочные каталоги. Текстовые файлы открываются во вкладках с подсветкой синтаксиса и доступны для редактирования. **Ctrl+S / Cmd+S**, потеря фокуса редактора или окна, переключение и закрытие вкладки сохраняют изменения на диск. При конфликте с изменениями на диске черновик сохраняется в редакторе и отображается ошибка. Внешние файлы и сравнения Git открываются для просмотра; Monaco загружается при первом открытии файла. Поиск по содержимому использует установленный `rg`, учитывает `.gitignore`, ищет буквальный текст без учёта регистра и открывает выбранную строку. Лимиты: текстовые файлы до 1 МБ, 200 результатов, до 5 строк на файл.

Изображения PNG, JPEG, GIF, WebP и AVIF из проекта и внешних файлов открываются в общем обзорщике. Колесо мыши масштабирует изображение под курсором с остановкой на 100% при переходе через исходный масштаб, перемещение с зажатой ЛКМ двигает его по области просмотра. Двойной клик центрирует изображение и возвращает исходный режим; «Сбросить масштаб» возвращает 100% и центрирует изображение, «Вписать» уменьшает или увеличивает изображение до размеров области и центрирует его. Фон выбирается прямо в обзорщике: светлый, тёмный, шашечки, градиенты или свой цвет. GIF сохраняет анимацию. Тот же механизм работает для SVG; смена цвета и размера SVG сохраняет зум и позицию просмотра.

SVG открывается с HTML-подсветкой исходника и рендером. Высота рендера и кода регулируется перетаскиванием горизонтальной границы. В крайних 10% панель схлопывается; граница остаётся доступной для раскрытия. Двойной клик или Enter восстанавливает прежнее соотношение; стрелки меняют высоту, Home / End скрывают одну из панелей. Можно менять `currentColor`, размер длинной стороны слайдером и числовым полем (8–2048 px) с сохранением пропорций и фон: светлый, тёмный, свой цвет, шашечки или градиенты. «Сбросить параметры SVG» возвращает стандартные цвет, размер и фон, сохраняя зум и положение изображения. «Сбросить масштаб» возвращает 100% и центрирует изображение, сохраняя параметры SVG. Настройки рендера действуют только в просмотре; исходник меняется при редактировании кода. Внешние SVG доступны без редактирования. При некорректной разметке отображается ошибка, исходник остаётся доступным.

Markdown (`.md`, `.markdown`) открывается как визуально редактируемый документ на Milkdown/Crepe: текст, заголовки, списки и таблицы изменяются прямо в оформленном виде. При выделении текста появляется панель форматирования. Верхней панели и кнопки сохранения нет: **Ctrl+S / Cmd+S**, потеря фокуса документа или окна, переключение и закрытие вкладки сохраняют файл на диск. Несохранённые изменения обозначены точкой вместо крестика во вкладке, запись — индикатором загрузки, ошибка — цветной точкой и сообщением в документе. Запись проверяет исходное содержимое и сохраняет черновик при конфликте с другим редактором. При уходе из проекта приложение сначала сохраняет изменения; ошибка сохранения требует подтверждения ухода. **Ctrl+Shift+M / Cmd+Shift+M** переключает документ и исходник для нестандартного Markdown. Ссылки открываются по **Ctrl+клик / Cmd+клик**, обычный клик устанавливает курсор. Локальные изображения загружаются из проекта (до 8 МБ). При визуальном редактировании библиотека может нормализовать маркеры списков, таблицы и ограждения блоков кода; открытие без правок не изменяет файл.

Архивы TAR, TGZ / TAR.GZ, TAR.BZ2, TAR.XZ и ZIP открываются в тех же вкладках как список записей с фильтром по пути, типами, размерами, датами и целями ссылок. Для отдельных GZIP (`.gz`, `.gzip`), BZIP2 и XZ отображается информация о сжатом файле. Метаданные читает сервер через стандартную библиотеку Python 3; файлы не извлекаются на диск. Лимиты просмотра: 5000 записей, 256 МБ чтения распакованного потока и 15 секунд; неполный список отмечается в интерфейсе. Проверки: `node --test tests/archives.test.mjs`.

Файлы и папки можно перетаскивать внутри проекта: на папку — внутрь неё, на файл — в его родительскую папку, на «Корень проекта» или свободное место под деревом — в корень. Папка назначения подсвечивается и раскрывается после наведения на 650 мс. Перенос обновляет дерево, Git, поиск и пути открытых файлов; раскрытые папки сохраняют своё состояние. Совпадение имён отклоняется без перезаписи; перенос внутрь себя, за пределы проекта и через символические ссылки запрещён. Для переноса используется установленный GNU `mv` с `--no-clobber`, `--no-target-directory` и `--no-copy`.

Правый клик по файлу, папке или корню открывает контекстное меню: создание, переименование, дублирование, вырезание, копирование и вставка, копирование путей и удаление с подтверждением. **F2**, **Delete**, **Ctrl+C / Ctrl+X / Ctrl+V** работают на сфокусированной записи дерева; **Shift+F10** открывает меню с клавиатуры. Копирование и перенос не перезаписывают существующие записи. Удалённые файлы и папки сохраняются в `.projector-trash` в корне проекта под именем с UUID; их можно восстановить вручную. Корзина скрыта из дерева, поиска и обзора Git.

Правый клик по вкладке позволяет закрыть её, остальные, вкладки слева или справа, все или только сохранённые файлы; меню файлов также предлагает сохранить черновик, скопировать путь и показать запись в дереве. Терминальные вкладки поддерживают переименование и групповое закрытие с подтверждением для работающих процессов. Меню используют Popover API и CSS Anchor Positioning с автоматической сменой стороны у края окна; навигация — стрелки, Home / End, Enter и Escape.

Действия дерева и табов проходят через SDK команд: например, `ide.fileTree.file.rename`, `ide.editor.tabs.closeOthers` и `ide.editor.file.save`. Меню и клавиши используют один обработчик и проверку доступности. Привязки задаются декларативно и сохраняются в `~/.local/share/projector/keybindings.json`; их можно переназначать без изменения компонентов. [SDK, аргументы и план дальнейшей миграции](ide-commands.md).

Git показывает ветку и отдельные деревья подготовленных и рабочих изменений. Выбор изменения открывает встроенный diff: **HEAD → index** или **index → рабочий файл**, включая новые, удалённые и переименованные файлы. Кнопка **↻** обновляет дерево, Git, поиск и активный файл после работы агента, сохраняя несохранённые черновики. Git diff остаётся доступен только для чтения.

Проверка дерева, переноса с защитой от перезаписи, ограничений чтения, Unicode-поиска и Git diff: `node --test tests/workspace.test.mjs` (также входит в `vp run test`).

Иконки дерева настраиваются через `public/file-icons/theme.json`: палитра, SVG и упорядоченные правила по именам, расширениям и путям. Добавление типа файла не требует правок компонентов. [Формат темы и примеры](file-icons.md). Проверка: `vp run test:file-icons`.

## Терминал в браузере

На странице проекта есть интерактивный терминал: **+ shell**, **+ Codex**, **+ Claude Code** создают отдельные сессии в папке проекта. Codex и Claude Code запускаются установленными командами `codex` и `claude` из окружения пользователя; установка и авторизация выполняются обычным способом через эти CLI. Можно также открыть shell и запустить любую команду вручную.

Терминал использует `node-pty`, xterm.js и WebSocket: поддерживает ввод, ANSI-цвета, Unicode, курсор, полноэкранные приложения, историю shell, Ctrl+C и изменение размера. Панель можно развернуть на весь экран. Ctrl+Shift+C копирует выделение, Ctrl+Shift+V вставляет текст; также работают стандартная вставка браузера и Shift+Insert.

Зажмите **Ctrl** и наведите мышь на путь в выводе терминала: распознанный путь подчёркивается, **Ctrl+click** открывает файл в рабочем пространстве. Поддерживаются относительные и абсолютные пути, `~/`, имена в кавычках с пробелами и координаты `file.ts:12:3` / `file.ts(12, 3)`. Относительные пути проверяются от текущей рабочей папки сессии, затем от корня проекта. HTTP/HTTPS-ссылки открываются в новой вкладке браузера. Распознавание читает только строку под курсором с её переносами и работает лишь при наведении с зажатым Ctrl; проверка файла на диске выполняется при клике.

Переключение вкладок, переход на другую страницу и перезагрузка браузера сохраняют процесс. При подключении восстанавливаются текущий экран, курсор, режимы терминала и до 5000 строк истории; выбранная вкладка запоминается в текущей вкладке браузера. Кнопка **закрыть сессию** завершает shell вместе с дочерними процессами. Удаление проекта и выход из Projector тоже закрывают его терминалы. Сессии живут в памяти сервера: перезапуск Projector завершает их.

Команды **dev / preview** также запускаются в терминальных сессиях. Одновременно можно держать несколько shell и агентов; общий лимит — 24 сессии. Медленная отрисовка приостанавливает чтение PTY до подтверждения браузером, а оборванное соединение восстанавливается автоматически.

Доступ разрешён через локальный адрес Projector; WebSocket проверяет Origin. Для сборки `node-pty` на Linux нужны Python, make и C++ compiler. Установка через `vp install` разрешает сборку этого модуля в `pnpm-workspace.yaml`.

Проверки PTY, ввода и восстановления: `tests/terminal.test.mjs` и `tests/terminal-input.test.mjs`; входят в `vp run test`.

## Агент Qwen

На странице проектов есть поле агента: путь или «найди vite проекты в ~/code». Qwen (OpenAI-compatible, как в ai-companion) сам читает `package.json` и добавляет проект.

Настройки: `/settings`. Ключ можно задать в UI или через `DASHSCOPE_API_KEY` / `OPENAI_URL` / `OPENAI_MODEL`. Провайдеры: `~/.local/share/projector/providers.json`.

В открытом проекте кнопка с роботом открывает вкладку **Агент**. Например: «открой
горячие клавиши» или «найди команду переименования файла и переименуй notes.md в
ideas.md». Агент сначала узнаёт существующие команды и их аргументы, затем вызывает
их через Projector. Для остальных задач доступен Bash в папке проекта.

Enter отправляет сообщение, Shift+Enter переносит строку. Кнопка **Остановить**
прерывает запрос и Bash. Переключение на файл сохраняет выполняющийся запрос;
закрытие чата и уход из проекта останавливают его. История каждого проекта хранится
на сервере в `$XDG_DATA_HOME/projector/agent` (по умолчанию
`~/.local/share/projector/agent`); **Очистить чат** удаляет её содержимое. Используется
активный AI-провайдер из настроек. Провайдер получает сообщения, путь проекта и
результаты вызванных инструментов.
