Локальный плагин

Установите набор тем из папки на этом компьютере. Projector проверит manifest.json и палитры перед добавлением.

Без архивов и установки зависимостей

Только данные, без кодаВсе установленные плагины декларативны.
  • Только цветовые токены и метаданные
  • Нет JavaScript, сети и доступа к файлам
  • Отключение сразу убирает темы из выбора
{
  "type": "theme",
  "version": "1.4.2",
  "themes": ["dark", "light"]
}
Плагины хранятся локально:
~/.local/share/projector/plugins
