# Lens: живая подпись к работе агента

Рабочий материал: прототип рядом с `/btw`. Решает другую задачу: не ответить на вопрос, а
постоянно показывать, чем агент занят, по видимой переписке. Если прототип приживётся, устройство
переедет в справочную документацию и `CHANGELOG.md`.

## Что делает

- Кнопка Lens в панели инструментов чата (иконка глаза) включает подпись; по умолчанию она
  выключена — это опциональная возможность.
- Подпись живёт в шапке блока «Работа» последнего ответа: в свёрнутом виде строка `LENS …` заменяет
  шаг инструмента, в раскрытом — встроенная строка под заголовком с текстом, временем и кнопками
  «Обновить», автообновление и «Скрыть». Своей рамки у неё нет: остаётся только разделитель между
  шапкой и списком ходов. На телефоне шапка с Lens закреплена, пока список прокручивается.
- Lens читает и рассуждения агента: они объясняют намерение, а не оставляют гадать по команде Bash.
- Пока агент занят и автообновление включено, запрос повторяется каждые 20 секунд; при старте и
  завершении хода — сразу. Тик пропускается, если шаг не изменился: подпись не просит тот же текст
  повторно. Ручное обновление работает всегда, в том числе во время ответа.
- У сабагента есть свой Lens: кнопка в строке задачи и в шапке её чата. Строка читает сессию
  сабагента по требованию, поэтому его работу можно смотреть, не открывая задачу; внутри задачи
  Lens показывает свою подпись рядом с её перепиской.
- До первого рассуждения или вызова блока «Работа» ещё нет: подпись показывается рядом с точками
  «Думает». Если в ответе вообще нет работы (только текст), Lens не показывается.

## Как устроено

- `src/modules/agent/model/lens.ts` — состояние одного чата (`open`, `text`, `at`, `auto`, `busy`,
  `error`), сборка контекста (`lensHistory`, `lensState`), подпись шага (`lensSignature`), таймер,
  отмена устаревших ответов и `lensActions` для команд.
- `src/modules/agent/model/task-turns.ts` — сессия сабагента по требованию и её повторное чтение,
  пока задача работает.
- `src/modules/agent/ui/AgentLens.vue` — встроенная строка без карточки; `AgentWork.vue`,
  `AgentTaskRow.vue` и `AgentTaskView.vue` только размещают её, данных о чате они не собирают.
- `src/modules/agent/api/lens.ts` — `POST /api/agent/lens`.
- `server/routes/api/agent-lens.ts` — только страница Projector (`accessAllowed`), разбор
  запроса, отмена по закрытию соединения.
- `server/modules/agent/lens-request.ts` — границы: 40 реплик, 12 инструментов, 30 пунктов плана.
- `server/modules/agents/projector/agent-lens.ts` — промпт и один `generateText`: тот же
  провайдер и модель, что в чате, без инструментов, без истории на диске, thinking погашен
  (`quietChatModel`). Ответ чистится до одной строки ≤ 400 символов.
- `server/modules/agents/projector/quiet-model.ts` — общий выбор «дешёвой» модели для Form Doctor
  и Lens.

## Контракт API

`POST /api/agent/lens`

```json
{
  "history": [
    { "role": "user", "content": "…" },
    { "role": "assistant", "content": "…", "thoughts": "…" }
  ],
  "state": {
    "busy": true,
    "phase": "думает",
    "running": [{ "name": "Bash", "input": "…", "startedAt": 1 }],
    "plan": [{ "content": "…", "status": "in_progress" }],
    "queue": 1
  },
  "selection": { "provider": "provider-id:model-alias" }
}
```

Ответ: `{ "text": "…", "at": 1760000000000 }`. Пустая история без занятости — `400`. Как и
`/api/agent/side`, запрос не создаёт run, не пишет историю и не продолжается после перезагрузки.

## Команды

- `ide.agent.lens.show` — включить и вернуть первую подпись.
- `ide.agent.lens.hide` — выключить и отменить запрос.
- `ide.agent.lens.refresh` — новая подпись.
- `ide.agent.lens.auto` — `enabled: boolean`, обновление по таймеру.

## Проверено

- `tests/agent-lens.test.mjs` — сборка истории и состояния, рассуждения в истории, ручное
  обновление, таймер только при занятом агенте и только при смене шага, ошибка сохраняет прежний
  текст, закрытие отбрасывает устаревший ответ.
- `tests/agent-task-turns.test.mjs` — сессия сабагента не читается до включения Lens, обновляется
  на таймере только пока задача работает и останавливается вместе с Lens.
- `tests/agent-lens-api.test.mjs` — полный `POST /api/agent/lens` с подставной моделью: промпт
  содержит историю, рассуждения, инструменты, план и очередь; ответ 200; run-файлов и истории нет;
  без Origin — 403, пустой запрос — 400; `lensLine` чистит markdown и режет до 400 символов.
- `tests/helpers/scripted-model.mjs` теперь отвечает JSON на нестриминговые запросы, поэтому
  `generateText` проверяется тем же скриптом.

## Ограничения прототипа

- Включение не сохраняется: после перезагрузки Lens снова выключен, при смене или очистке чата
  сбрасывается.
- Подпись не потоковая: сначала приходит целиком, промежуточных токенов нет.
- Каждое обновление — отдельный платный запрос с историей до 12 000 символов; таймер работает
  только пока агент занят, скрытая вкладка не опрашивается.
- Один блок на ответ: подпись привязана к последней группе «Работы» последнего ответа.
- Ошибки показываются в панели и не пишутся в лог; при неудаче остаётся прежняя подпись.
- Внешние агенты (Claude Code, Codex и другие) тоже видят Lens: модель для подписи — провайдер
  Projector из настроек, а не агент чата.
