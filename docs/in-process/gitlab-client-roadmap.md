# GitLab: что осталось после паритета

Рабочий документ: только открытые пункты. P0–P3 реализованы; текущее устройство — [integrations.md](../integrations.md), профили workspace — [architecture.md](../architecture.md).

Паритет с GitHub по чтению и клонированию закрыт: `gl:/`, файлы и Markdown, Issues, Merge requests, история Git, клонирование с задачами и Docker, локальные проекты, палитра, Device Flow и refresh. Ниже — только то, что осталось.

## P4. После паритета

- [ ] Snippets и Wiki в readonly-режиме.
- [ ] Несколько инстансов одновременно: список в `integrations.json`, токен на хост, настройки на каждый инстанс. Ссылки уже содержат authority, но `integration-store` пока хранит один `gitlab`.
- [ ] Кеш и ETag для деревьев и файлов, бюджет лимитов API, повторные запросы без мигания вкладок.
- [ ] Вынести общий `code-host` для GitHub и GitLab, если дублирование профилей, клиентов и диалогов клонирования станет дороже поддержки.

## Известные ограничения

- [ ] Приватный проект без токена GitLab отвечает `404`, поэтому вкладка подключения открывается только на `401/403`. Для настроенного инстанса без входа показывать подключение и на `404`, если проект не публичный (нужен аккуратный признак, чтобы не прятать настоящий «не найден»).
- [ ] `gl:/` не поддерживает установочный префикс в самой ссылке — он хранится в настройках инстанса. Это осознанное решение; проверить, не ломает ли оно ссылки, скопированные из self-hosted с префиксом.
- [ ] Комментарии и файлы MR читаются до 500/300; при усечении интерфейс сообщает об этом. Отдельного «догрузить всё» нет.

## Проверки перед закрытием

- [ ] `vp run check` целиком (архитектура, все тесты, типы, сборка).
- [ ] Ручной прогон: gitlab.com публичный и приватный; self-hosted с префиксом и вложенными группами; пустой проект; только README; файл больше 5 MiB; бинарный файл; подмодуль; симлинк; MR с approvals; issue с системными notes; pipeline с несколькими стадиями, failed job и усечённым логом; 429 и истёкший токен.
- [ ] Реальный Device Flow на инстансе с зарегистрированным OAuth Application (в тестах только mocked fetch).
- [ ] Проверить Docker-клон self-hosted: DNS/HTTPS, приватный CA и доступ к локальному хосту из контейнера.
- [ ] Мобильная раскладка и клавиатура в `gl:/`-workspace; правый клик и фокус после HMR.
