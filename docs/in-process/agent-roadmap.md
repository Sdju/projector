# Дорожная карта штатного агента Projector

Рабочий документ: только открытые пункты, сделанное удаляется. Устройство агента — [архитектура](../architecture.md) и профильные документы `agent-*.md`.

## Агент

- [ ] Бюджет токенов размышления: `thinking_budget` для Qwen, `reasoning.max_tokens` для OpenRouter (`packages/server/modules/providers/thinking.ts`).
- [ ] Явный `cache_control` для Anthropic/Gemini через OpenRouter: SDK кладёт его на уровень сообщения, OpenRouter ждёт в части содержимого; нужна проверка на живом API.
- [ ] `task` — субагент для read-only исследования в отдельном контексте; результат — сводка. Должен принимать `role` (снимок chat-роли уже передаётся в `AgentRunOptions`/`AgentRunRecord`).
- [ ] Расход: цена ответа и всего чата уже считается; открыты цены по умолчанию для известных моделей, учёт сжатия истории и проверки команд, расход за период.
- [ ] Расписание и триггеры по событиям; нужно решение о правах без пользователя.

## MCP, веб, навыки, хуки

- [ ] MCP: OAuth удалённых серверов, ресурсы и промпты, соединения дольше одного хода.
- [ ] Веб: PDF и другие не текстовые форматы, JavaScript-страницы, кэш.
- [ ] Навыки: хранить в истории развёрнутый текст команды вместо `/имя`; создание навыков из интерфейса; `allowed-tools`; вложенные папки команд.
- [ ] Хуки: `SessionStart`; изменение ввода инструмента ответом хука; запуск хуков в `/compact`.

## Делегирование

- [ ] Очередь при реальной нехватке ресурсов: сейчас задания стартуют сразу, `queued` — короткое состояние до запуска.
- [ ] Прогон evals делегирования на двух моделях с сохранением результатов для сравнения.
