# Lens: живая подпись о работе агента

Необязательная короткая сводка «чем агент занят сейчас» в шапке блока **Работа**. Читает переписку, рассуждения и состояние чата, но не отвечает на вопрос и не меняет ход. Включается в меню «Ещё → Lens», по умолчанию выключена.

## Поведение

- В свёрнутом «Работе» строка `Lens …` заменяет текущий шаг инструмента; в раскрытом стоит под заголовком с кнопками «Обновить», автообновление и «Скрыть».
- Пока агент занят и автообновление включено, запрос идёт каждые 20 секунд. Тик пропускается, если шаг не изменился: та же подпись повторно не запрашивается. Ручное обновление работает всегда.
- Первые секунды хода запрос не тратится: до первого рассуждения, текста или вызова показывается «Агент обдумывает задачу…». Первый запрос уходит, когда рассуждение накопилось (~1,5 с) или сменился шаг — появился/завершился вызов, начался текст, сдвинулся план. Переход между вызовами запрос не вызывает.
- Самое свежее рассуждение передаётся отдельным блоком, поэтому Lens называет намерение, а не пересказывает команду. Последняя подпись подводит итог при завершении; если в ответе только текст, Lens не показывается.
- У сабагента свой Lens: кнопка в строке задачи и в шапке его чата. Сессия читается по требованию, пока задача работает.
- На телефоне шапка «Работы» с Lens закреплена, пока список шагов прокручивается.

## Как устроено

- `packages/client/modules/agent-turns/model/lens.ts` — состояние чата (`open`, `text`, `at`, `auto`, `busy`, `error`), сборка контекста (`lensHistory`, `lensState`), готовность (`lensHasMaterial`), смена шага (`lensStep`), подпись (`lensSignature`), таймер, отложенный запрос после первой мысли, отмена устаревших ответов и `lensActions`.
- `packages/client/modules/agent-turns/model/task-turns.ts` — сессия сабагента по требованию и повторное чтение, пока задача работает.
- `packages/client/modules/agent-turns/ui/AgentLens.vue` — строка без карточки; `AgentWork.vue`, `AgentTaskRow.vue`, `AgentTaskView.vue` только размещают её.
- `POST /api/agent/lens` (`packages/server/routes/api/agent-lens.ts`) — только страница Projector (`accessAllowed`), отмена по закрытию соединения.
- `packages/server/modules/agent/lens-request.ts` — границы: 40 реплик, 12 инструментов, 30 пунктов плана; страница отправляет не больше 20 реплик и 8 выполняющихся вызовов.
- `packages/server/modules/agents/projector/agent-lens.ts` — промпт и один `generateText`: провайдер и модель роли `lens` (по умолчанию — модель чата), без инструментов, без истории на диске, thinking погашен (`quietChatModel`). Свежее рассуждение дублируется отдельным блоком. Ответ чистится до одной строки ≤ 400 символов; если описывать нечего, сервер возвращает «Агент обдумывает задачу…» без вызова модели.
- `packages/server/modules/providers/quiet-model.ts` — общий выбор дешёвой модели для Form Doctor, Lens и Судьи; модель каждой роли задаётся в разделе «Роли агентов» ([подробно](agent-roles.md)).

Lens — отдельный процесс чтения, а не второй агент: не создаёт run-файл, не пишет историю, не продолжается после перезагрузки и не имеет инструментов.

## API

`POST /api/agent/lens`

```json
{
  "history": [
    { "role": "user", "content": "…" },
    { "role": "assistant", "content": "…", "thoughts": "…" }
  ],
  "state": {
    "busy": true,
    "phase": "думает",
    "running": [{ "name": "Bash", "input": "…", "startedAt": 1 }],
    "plan": [{ "content": "…", "status": "in_progress" }],
    "queue": 1
  },
  "selection": { "provider": "provider-id:model-alias" }
}
```

Ответ: `{ "text": "…", "at": 1760000000000 }`. Пустая история без занятости — `400`, без Origin — `403`. Запрос ограничен 20 секундами и 200 токенами ответа.

## Команды

- `ide.agent.lens.show` — включить и вернуть первую подпись.
- `ide.agent.lens.hide` — выключить и отменить запрос.
- `ide.agent.lens.refresh` — новая подпись.
- `ide.agent.lens.auto` — `enabled: boolean`, обновление по таймеру.

## Ограничения

- Включение не сохраняется: после перезагрузки Lens выключен, при смене или очистке чата сбрасывается.
- Подпись не потоковая и привязана к блоку «Работа» последнего ответа.
- Каждое обновление — отдельный платный запрос с историей до 12 000 символов; таймер работает только пока агент занят, скрытая вкладка не опрашивается.
- Ошибки показываются в панели и не пишутся в лог; при неудаче остаётся прежняя подпись.
- Внешние агенты тоже видят Lens: модель — провайдер Projector из настроек, а не агент чата.
- Фоновый `subagent` OpenCode не отдаёт дочернюю сессию: задача появляется, но Lens читает только постановку. Разбор — [opencode-background-subagents](in-process/opencode-background-subagents.md).
