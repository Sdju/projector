# Lens: живая подпись о работе агента

Lens — необязательная короткая сводка «чем агент занят сейчас» в шапке блока **Работа**. Она читает видимую переписку, рассуждения агента и живое состояние чата, но не отвечает на вопрос и не меняет ход.

## Как пользоваться

- **Ещё → Lens** в шапке чата включает подпись; по умолчанию она выключена.
- В свёрнутом блоке «Работа» строка `Lens …` заменяет текущий шаг инструмента, в раскрытом — стоит под заголовком вместе с текстом, временем и кнопками «Обновить», автообновление и «Скрыть».
- Пока агент занят и автообновление включено, запрос повторяется каждые 20 секунд. Тик пропускается, если шаг не изменился: подпись не просит тот же текст повторно. Ручное обновление работает всегда, в том числе во время ответа.
- Первые секунды хода Lens не тратит запрос: пока нет рассуждения, текста или вызова, показывается локальная строка «Агент обдумывает задачу…». Первый запрос уходит, когда рассуждение накопилось (примерно через 1,5 секунды), или сразу при смене шага — появился или завершился вызов, начался текст, сдвинулся план. Переход от одного вызова к другому запрос не вызывает: его подхватывает обычный таймер.
- Рассуждение — главный источник подписи: самое свежее передаётся отдельным блоком, а не только внутри истории. Поэтому Lens называет намерение, а не пересказывает команду.
- Последняя подпись подводит итог при завершении хода. Если в ответе нет работы (только текст), Lens не показывается.
- До первого рассуждения или вызова блока «Работа» ещё нет: подпись показывается рядом с точками «Думает».
- У сабагента свой Lens: кнопка в строке задачи и в шапке её чата. Строка читает сессию сабагента по требованию, поэтому его работу можно смотреть, не открывая задачу; внутри задачи Lens стоит рядом с перепиской.
- На телефоне шапка блока «Работа» с Lens закреплена, пока список шагов прокручивается.

## Как устроено

- `src/modules/agent/model/lens.ts` — состояние одного чата (`open`, `text`, `at`, `auto`, `busy`, `error`), сборка контекста (`lensHistory`, `lensState`), готовность ответа к описанию (`lensHasMaterial`), грубая смена шага (`lensStep`), полная подпись (`lensSignature`), таймер, отложенный запрос после первой мысли, отмена устаревших ответов и `lensActions` для команд.
- `src/modules/agent/model/task-turns.ts` — сессия сабагента по требованию и её повторное чтение, пока задача работает.
- `src/modules/agent/ui/AgentLens.vue` — встроенная строка без карточки; `AgentWork.vue`, `AgentTaskRow.vue` и `AgentTaskView.vue` только размещают её, данных о чате они не собирают.
- `src/modules/agent/api/lens.ts` — `POST /api/agent/lens`.
- `server/routes/api/agent-lens.ts` — только страница Projector (`accessAllowed`), разбор запроса, отмена по закрытию соединения.
- `server/modules/agent/lens-request.ts` — границы: 40 реплик, 12 инструментов, 30 пунктов плана; страница отправляет не больше 20 реплик и 8 выполняющихся вызовов.
- `server/modules/agents/projector/agent-lens.ts` — промпт и один `generateText`: тот же провайдер и модель, что в чате, без инструментов, без истории на диске, thinking погашен (`quietChatModel`). Самое свежее рассуждение дублируется отдельным блоком перед состоянием. Ответ чистится до одной строки ≤ 400 символов; если описывать ещё нечего, сервер возвращает ту же строку «Агент обдумывает задачу…» без вызова модели.
- `server/modules/agents/projector/quiet-model.ts` — общий выбор «дешёвой» модели для Form Doctor и Lens.

Lens — отдельный процесс чтения, а не второй агент: он не создаёт run-файл, не пишет историю, не продолжается после перезагрузки и не получает доступ к инструментам.

## Контракт API

`POST /api/agent/lens`

```json
{
  "history": [
    { "role": "user", "content": "…" },
    { "role": "assistant", "content": "…", "thoughts": "…" }
  ],
  "state": {
    "busy": true,
    "phase": "думает",
    "running": [{ "name": "Bash", "input": "…", "startedAt": 1 }],
    "plan": [{ "content": "…", "status": "in_progress" }],
    "queue": 1
  },
  "selection": { "provider": "provider-id:model-alias" }
}
```

Ответ: `{ "text": "…", "at": 1760000000000 }`. Пустая история без занятости — `400`. Без Origin — `403`. Запрос ограничен 20 секундами и 200 токенами ответа.

## Команды

- `ide.agent.lens.show` — включить и вернуть первую подпись.
- `ide.agent.lens.hide` — выключить и отменить запрос.
- `ide.agent.lens.refresh` — новая подпись.
- `ide.agent.lens.auto` — `enabled: boolean`, обновление по таймеру.

## Проверки

- `tests/agent-lens.test.mjs` — сборка истории и состояния, рассуждения в истории, локальная строка до первой мысли и запрос после неё, отсутствие запроса на каждый токен рассуждения, ручное обновление, таймер только при занятом агенте и только при смене шага, ошибка сохраняет прежний текст, закрытие отбрасывает устаревший ответ.
- `tests/agent-task-turns.test.mjs` — сессия сабагента не читается до включения Lens, обновляется на таймере только пока задача работает и останавливается вместе с Lens.
- `tests/agent-lens-api.test.mjs` — полный `POST /api/agent/lens` с подставной моделью: промпт содержит историю, свежее рассуждение отдельным блоком, инструменты, план и очередь; ответ 200; run-файлов и истории нет; без Origin — 403, пустой запрос — 400; до первого рассуждения модель не вызывается; `lensLine` чистит markdown и режет до 400 символов.

## Ограничения

- Включение не сохраняется: после перезагрузки Lens снова выключен, при смене или очистке чата сбрасывается.
- Подпись не потоковая: сначала приходит целиком, промежуточных токенов нет.
- Каждое обновление — отдельный платный запрос с историей до 12 000 символов; таймер работает только пока агент занят, скрытая вкладка не опрашивается.
- Один блок на ответ: подпись привязана к блоку «Работа» последнего ответа.
- Ошибки показываются в панели и не пишутся в лог; при неудаче остаётся прежняя подпись.
- Внешние агенты (Claude Code, Codex и другие) тоже видят Lens: модель для подписи — провайдер Projector из настроек, а не агент чата.
- Фоновый `subagent` OpenCode пока не отдаёт Projector дочернюю сессию: задача появляется, но Lens в её строке читает только постановку, без рассуждений. Разбор и варианты — в [рабочих материалах](in-process/opencode-background-subagents.md).
