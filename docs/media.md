# Медиа-модели

Единый серверный API для изображений, синтеза речи, распознавания и видео. Провайдер подключается адаптером, поэтому маршруты, задачи и артефакты одинаковы для QwenCloud, OpenAI-совместимых серверов и будущих плагинов.

Код: контракты — `packages/core/modules/media`, реестр и сервис — `packages/server/modules/media`, встроенные адаптеры — `packages/server/modules/media-qwencloud` и `packages/server/modules/media-openai`, маршруты — `packages/server/routes/api/media.ts`.

## Маршруты

| Метод и путь                         | Назначение                                                                                          |
| ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| `GET /api/media`                     | Включённые провайдеры с медиа-адаптером и их возможности                                            |
| `GET /api/media/models?capability=…` | Модели по возможности: `image.generate`, `speech.synthesize`, `speech.transcribe`, `video.generate` |
| `POST /api/media/generate`           | Запуск генерации; `200` — готовый результат, `202` — фоновая задача                                 |
| `GET /api/media/jobs/:id`            | Состояние задачи и артефакты                                                                        |
| `POST /api/media/jobs/:id/cancel`    | Отмена задачи у провайдера                                                                          |
| `GET /api/media/files/:id`           | Скачанный артефакт с `Content-Type` и `no-store`                                                    |
| `POST /api/media/keys/temporary`     | Временный ключ QwenCloud `st-…`; только с локальной машины                                          |

`POST /api/media/keys/temporary` принимает `{ providerId, expiresIn }`, где `expiresIn` — от 1 до 1800 секунд, по умолчанию 600. Ключ наследует права сохранённого ключа и не является балансовым.

## Запрос

```json
{
  "capability": "image.generate",
  "providerId": "qwen-dashscope",
  "model": "qwen-image-3.0-pro",
  "prompt": "кот в окне",
  "options": { "size": "1024*1024", "n": 1 }
}
```

`providerId` необязателен: без него берётся активный провайдер. Если модель не перечислена в каталоге, запрос всё равно уходит провайдеру — так новые модели не требуют обновления Projector.

Входные файлы передаются как ссылки или base64:

```json
{
  "capability": "speech.transcribe",
  "model": "qwen-audio-3.1-asr-flash",
  "input": {
    "audio": { "url": "https://example.com/a.wav" }
  }
}
```

`input.images` добавляет изображения к запросу генерации/редактирования, `input.text` заменяет `prompt` для TTS и ASR, `input.audio.url` нужен для видео с озвучкой.

## Ответ и задачи

Синхронная генерация возвращает `200` и задачу со статусом `succeeded`. Видео, async-изображения и длинное распознавание возвращают `202`, заголовок `Location` и `jobId`:

```json
{
  "id": "e3e7…",
  "status": "running",
  "capability": "video.generate",
  "providerId": "qwen-dashscope",
  "adapter": "qwencloud",
  "artifacts": [],
  "createdAt": 1760000000000,
  "updatedAt": 1760000000000
}
```

`artifacts` содержит `fileId` (локальная копия), `mime`, `kind`, исходный `url` и срок его жизни. Для распознавания вместо файла приходит `text`.

Задачи живут в памяти процесса: после перезапуска сервера незавершённые задачи исчезают, а уже скачанные файлы остаются. Отмена вызывает `POST /tasks/{id}/cancel` у QwenCloud. Параллельные опросы одной задачи объединяются, отмена ждёт активный опрос, а терминальный статус необратим. `progress` всегда находится в диапазоне от 0 до 1.

## Артефакты

- Скачиваются сразу в `$XDG_DATA_HOME/projector/media/files`, индекс — `media/artifacts.json`.
- Пределы: изображение 32 МиБ, аудио 64 МиБ, видео 512 МиБ, текст 2 МиБ. Тело API-запроса ограничено 100 МиБ; потоковые загрузки останавливаются при превышении лимита.
- Скачивание только по HTTPS, без redirect и с таймаутом. Приватные адреса запрещены; QwenCloud дополнительно ограничен хостами `aliyuncs.com` и `qwencloudapi.com`.
- Сохраняются только безопасные image/audio/video MIME-типы. Файл отдаётся по `/api/media/files/<id>` с `nosniff`, sandbox CSP и `same-origin`; произвольные пути не отдаются.
- Автоматической очистки пока нет: файлы удаляются вручную вместе с каталогом.
- Ключи провайдеров не попадают ни в ответы, ни в индекс, ни в логи.

## QwenCloud

Адаптер `qwencloud` принимает и новый домен `https://<region>.maas.qwencloudapi.com`, и старый `https://dashscope-intl.aliyuncs.com`. Из адреса строится `/api/v1`; ключ должен быть создан в том же регионе. Текст и модели того же провайдера идут в `/compatible-mode/v1`: общий разбор адреса в `packages/core/modules/providers/qwencloud.ts` превращает origin, `/api/v1` и `/apps/anthropic` в правильную базу для чата, а незнакомый путь прокси оставляет как есть. Ошибка `401` чаще всего означает несовпадение региона, а не неверный ключ.

| Возможность   | Модели                                                                                                 | Особенности                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| Изображения   | `qwen-image-3.0-pro`, `qwen-image-3.0`, `qwen-image-2.1-pro`, `qwen-image-2.1-turbo`, `qwen-image-2.0` | `size` в форме `1024*1024`; async — `options.async`                                   |
| Синтез речи   | `qwen3-tts-flash`                                                                                      | `voice` (по умолчанию `Cherry`), `language_type`; URL живёт 24 часа                   |
| Распознавание | `qwen-audio-3.1-asr-flash`                                                                             | Синхронно, URL или data URI; фоновое распознавание пока не подключено                 |
| Видео         | `wan3.0-video`, `wan2.6-t2v`, `wan2.6-i2v`                                                             | `resolution`, `ratio` или `size`, `duration`; статус опрашивается каждые 10–15 секунд |

Временный ключ выдаётся через `POST /api/v1/tokens?expire_in_seconds=N`. Постоянные ключи создаются только в консоли QwenCloud. Баланс по ключу API не читается — см. [рабочий документ](in-process/qwencloud-media-integration.md).

## Другие провайдеры

Встроенный адаптер `custom` работает с OpenAI-совместимыми `/images/generations`, `/audio/speech` и `/audio/transcriptions`. Модели: `gpt-image-1`, `dall-e-3`, `gpt-4o-mini-tts`, `tts-1`, `whisper-1`, `gpt-4o-mini-transcribe`. Видео у него нет.

Новый провайдер — это объект `MediaAdapter` с `kind`, `capabilities`, `listModels`, `submit` и необязательными `poll`/`cancel`; регистрация — `registerMediaAdapter`. `artifactHosts` задаёт allowlist хостов результатов, а каталог ограничивает допустимые capability известных моделей. Адаптер получает адрес и расшифрованный ключ провайдера, поэтому отдельного хранилища секретов не нужно. Реестр не содержит условий по имени провайдера: всё различие остаётся в адаптере.

## Агент и виджеты

Агент работает через те же команды `ide.media.*`, что и вкладка. Они регистрируются один раз при старте приложения, в области `media`, а не компонентом вкладки, поэтому генерация и чтение задачи доступны, даже когда вкладка «Медиа» закрыта. Команда возвращает задачу с артефактами, а не только меняет экран:

| Команда                    | Аргументы                                                                                 | Результат                                          |
| -------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `ide.media.models.refresh` | `capability?`                                                                             | `{ state, models }`: провайдеры, адаптеры и модели |
| `ide.media.generate`       | `capability`, `model`, `prompt`, `providerId`, `imageUrl`, `audioUrl`, `options`, `input` | `MediaJob` с `fileUrl` и `widget`                  |
| `ide.media.job.refresh`    | `id`                                                                                      | Обновлённая задача и опрос провайдера              |
| `ide.media.job.cancel`     | `id`                                                                                      | Задача со статусом `cancelled`                     |
| `ide.media.result.clear`   | —                                                                                         | Только экран вкладки; команда живёт в её области   |

Встроенный агент вызывает их через `execute_command`, внешний — через MCP `projector-ide` (`list_commands` → `describe_command` → `execute_command`). `ide.media.generate` не считается безопасной командой, поэтому Projector спрашивает подтверждение с моделью, запросом и параметрами; `refresh` и чтение задачи проходят без вопроса.

Ответ команды — та же `MediaJob`, но у артефактов появляется `fileUrl` (`/api/media/files/<id>`), а у завершённой задачи — поле `widget` с готовым тегом `<Media jobId="…" />`. Агент вставляет этот тег в ответ: виджет сам читает `/api/media/jobs/:id`, опрашивает выполняющуюся задачу и показывает изображение, аудио, видео или текст распознавания. Для одной картинки можно вместо виджета использовать `<Image src=fileUrl alt="…" />`.

`<Media>` — специальный виджет: в постоянной справке остаётся одна строка, полные свойства выдаёт `ide.chat.widgets.describe` через общий `execute_command`. После перезапуска сервера задачи исчезают, а скачанные файлы остаются, поэтому для истории подходит `<Media fileId="…" kind="image" />`.

Любой агент с доступом к машине может обойтись без команд и вызвать API напрямую:

```bash
curl -s http://localhost:4177/api/media/generate \
  -H 'Content-Type: application/json' \
  -d '{"capability":"image.generate","model":"qwen-image-3.0-pro","prompt":"кот в окне"}'
```

В ответе будет `id` задачи, `artifacts[].fileId`, ссылка `/api/media/files/<id>` и поле `widget`. Достаточно вставить этот тег в ответ — виджет сам прочитает задачу. Если `status` равен `queued` или `running`, задача опрашивается через `GET /api/media/jobs/<id>`.

## Клиент

Генерация живёт во вкладке workspace **«Медиа»**: кнопка с искрами на панели инструментов или команда `ide.media.open` (Ctrl+Shift+P). Вкладка показывает возможности включённых провайдеров, модели и форму генерации. Модель выбирается по возможности, размеру, голосу и длительности; результат (изображение, аудио, видео или текст распознавания) показывается на месте, а фоновая задача опрашивается автоматически.

Команды:

| Команда                    | Назначение                                                                                                      |
| -------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `ide.media.models.refresh` | Перечитать провайдеров и модели                                                                                 |
| `ide.media.generate`       | Запустить генерацию; аргументы `capability`, `providerId`, `model`, `prompt`, `imageUrl`, `audioUrl`, `options` |
| `ide.media.job.refresh`    | Перечитать задачу по `id`                                                                                       |
| `ide.media.job.cancel`     | Отменить задачу по `id` у провайдера                                                                            |
| `ide.media.result.clear`   | Убрать результат с экрана; файлы остаются                                                                       |

`ide.media.generate` принимает аргументы и не зависит от заполненной формы; вкладка передаёт в нее те же значения. Команды работают в scope `media`, который регистрируется при старте приложения, а `ide.media.result.clear` — в scope `mediaPanel`, потому что меняет только экран. Агент видит команды вместе с остальными `ide.*`.

Провайдер с читателем расхода дополнительно показывает блок «расход провайдера» и команду `ide.providers.usage.refresh`; для QwenCloud читатель запускает CLI, для других видов его подключает свой модуль ([интеграции](integrations.md)).

## Ограничения

- Сохранения результата в папку проекта пока нет; файл доступен по локальной ссылке Projector.
- Локальная загрузка файлов для QwenCloud не реализована; принимаются публичные URL и base64. Token Plan-ключи (`sk-sp-`) локальные файлы не принимают и в самом QwenCloud.
- Фоновое распознавание длинных файлов (Fun-ASR/Paraformer) не подключено: распознавание синхронное.
- TTS отдаётся готовым файлом; стриминг `X-DashScope-SSE` не подключён.
- OpenAI-совместимые медиа-маршруты под `/api/openai/v1` не добавлены: это отдельный слой поверх того же реестра.
- Задачи не переживают рестарт сервера, а артефакты не чистятся по возрасту.
