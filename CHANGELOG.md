# Changelog

## 0.1.0

Первый публичный выпуск Projector из исходников для Linux.

* GTK-палитра для поиска приложений и проектов, трей и горячая клавиша.
* Веб-интерфейс и режим отдельного окна Chromium.
* Каталог проектов, команды из `package.json` и терминалы Shell, Codex и Claude Code.
* Обзор файлов, поиск, редактирование текста и Markdown, просмотр архивов, изображений и SVG.
* Git: изменения, diff, stage/unstage и групповые действия.
* Интеграция GitHub: PAT или OAuth Device Flow, список репозиториев и импорт.
* Настройки, ключи интеграций и состояние рабочего пространства сохраняются на диске.
* Пакет `vio`: Vue renderer для нативных GTK4-приложений.

Проверенное desktop-окружение — KDE Plasma/X11. Установка требует Node.js 24,
Vite+, GTK4 и системных зависимостей. Самостоятельный бинарный дистрибутив
в этот выпуск не входит; Projector запускает локальный сервер через `vp dev`.
