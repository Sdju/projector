# Icon sources

The Projector Pastel theme uses a Catppuccin Mocha palette and icons extracted from the installed Iconify collections. No VSCode extension assets are included.

- Lucide (`@iconify-json/lucide`): Lucide Icons and Contributors, ISC; some icons derive from Feather (Cole Bemis, MIT). Full license: [LICENSE-lucide.txt](LICENSE-lucide.txt). Source: https://github.com/lucide-icons/lucide
- Simple Icons (`@iconify-json/simple-icons`): Simple Icons Collaborators, CC0 1.0. Source and license: https://github.com/simple-icons/simple-icons and https://creativecommons.org/publicdomain/zero/1.0/

Simple Icons provides the language/framework logos: git, typescript, javascript, vue, react, html, css, sass, python, rust, go, ruby, php, c, cpp, docker, vite, svelte, kotlin, swift, graphql. Other SVG files use Lucide. Logo names and designs belong to their respective owners.
