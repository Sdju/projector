# Разработка

Требования и устройство проекта описаны в [AGENTS.md](AGENTS.md) и
[архитектуре](docs/architecture.md). Все корни используют FEOD: импортируйте
модули через публичные `index.ts` и сохраняйте границы платформ.

```bash
vp install --frozen-lockfile
vp run check
vp run vio:gtk-test
```

Последняя команда требует доступного display. В CI она запускается через Xvfb.
При изменениях интерфейса проверяйте реальное взаимодействие в GTK или браузере.

Перед запуском или перезапуском выясните состояние работающего сервера через
`/api/health` и `/api/status`: завершение Projector останавливает его терминалы
и дочерние процессы.

В issue укажите окружение, шаги воспроизведения и ожидаемый результат.
Не прикладывайте файлы провайдеров, интеграций, токены или приватные проекты.
