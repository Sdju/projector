# Docker и Compose

- Команды управления находятся в scope `docker:<projectId>` (`ide.docker.*`): состояние, Compose-привязка, контейнеры, логи, shell и порты.
- Настройки подключения находятся в scope `docker:settings` на странице настроек Projector.
- Действия возвращают терминальную сессию: перед заявлением об успехе обязательно проверь её `exitCode` (через `ide.workbench.tab.read` или возвращённый статус).
- Удаление контейнеров выполняй только по явной просьбе пользователя; при удалении `volumes` сохраняются.
